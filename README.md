# U STUDIO USHIO — 更新体験デモ

Yuiが制作する営業・提案用のデモです。公式サイトではありません。写真・コピー・デザインは提案用の見本です。

## できること

- チャット欄からメインの見出しを変更（60文字まで）
- ピンク・ブルー・ラベンダー・ナチュラルの配色に変更
- ウェディング／成人式・卒業式／七五三・キッズの順番を変更
- 直前の状態へ戻す、初期状態へ戻す、PC・スマートフォン幅の表示

対応する言い回しを解釈して見本だけを変更する静的な操作デモです。AI API、認証情報、顧客データ、実際のサイト更新・予約・送信機能はありません。履歴はブラウザのメモリ内だけに保持し、再読込で初期化します。公式サイトへ移動するリンクは移動先が分かる表記にしています。

## 構成と確認

| ファイル | 役割 |
| --- | --- |
| index.html / studio.css | 編集体験の画面 |
| preview.html / preview.css | サイトの見本 |
| engine.mjs | 指示の解釈 |
| app.mjs | 画面と履歴の制御。入力はtextContentで反映 |
| assets/ | サンプル写真（Unsplash） |
| engine.test.mjs | 指示の解釈・未対応指示の検証 |

依存パッケージ、ビルド、サーバーは不要です。`node --test engine.test.mjs`で確認できます。GitHub Pagesでmainブランチのルートを公開します。停止はリポジトリSettings → Pagesで公開を無効化します。

画像の出所は assets/sources.json を参照。画像は実際の店舗・撮影実績を示すものではありません。[Unsplash License](https://unsplash.com/license)。公開先・検証結果は下記へ記録します。
